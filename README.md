# The Dream IAS Satna — Corporate Aptitude Portfolio

A responsive HTML/CSS/JavaScript landing page for The Dream IAS Satna's Corporate Aptitude Batch.

## Run in VS Code

1. Extract the ZIP.
2. Open the `the-dream-ias-portfolio` folder in VS Code.
3. Open `index.html`.
4. Use **Live Server** extension, or open `index.html` directly in a browser.

## Files

- `index.html` — main website
- `style.css` — responsive design and styling
- `script.js` — scroll reveal animations
- `assets/logo.png` — supplied institute logo
- `assets/location.png` — supplied location image
